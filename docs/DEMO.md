# 3-Minute Demo

1. Login with demo credentials.
2. Show the dashboard KPI cards.
3. Open a denial.
4. Point to the reason, confidence, RAG evidence and appeal draft.
5. Explain that routine high-confidence cases can become AUTO_READY.
6. Explain that low-confidence or high-value cases become HUMAN_REVIEW.
7. Show the architecture and emphasize local Ollama inference.
8. State: "The AI does not have the final authority; the confidence gate decides
   when automation must stop."
